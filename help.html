Report a problem

Use the Report option on a post or room to send a report to Frnxup moderators. For a suspended account, return to the login page and enter the correct password. Frnxup will display a secure appeal button only after it verifies that the account is suspended. Permanently banned accounts should contact frnxup@gmail.com.
