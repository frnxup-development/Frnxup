EDU-AFRIKA EXAM AUTOMATION ROOM

Build the approved question bank used to assemble randomized student practice examinations.

How question automation worksAdmins create, import, review and publish questions here. The database builds each candidate's paper from their examination, verified course / stream / trade / module, selected subjects, question formats and mode. A global one-time delivery ledger prevents the same normalized question content from being issued to another attempt; if the unused pool is too small, the system refuses the paper instead of reusing questions. Answer keys stay private until submission.

2. Choose question destinations and generateOne selected subject creates one destination batch. Select several subjects for sequential bulk generation. Each batch is tagged with its examination, subject, programme, syllabus year and topic.

Generated items are original practice drafts, not official JAMB, WAEC, NECO or other past questions. They are saved unpublished in the review queue. The AI system checks structure, topic routing, global exact duplicates, near-duplicates against recent bank items and a second-pass consistency signal; it cannot certify that an answer or syllabus mapping is correct. Human academic review is strongly recommended. An administrator may explicitly authorize direct release in the publishing controls below.
