# EDU-AFRIKA dedicated examination pages

Each active exam code has its own page in this folder. Select an exam in the student workspace and choose **Open this exam's dedicated webpage**, or visit its matching HTML file directly.

Official graphical logos are intentionally not synthesized. Upload the exact original artwork from the examination body or authorized brand kit in **Admin → EDU-AFRIKA EXAM AUTOMATION ROOM → Official examination logo library**. The page reads the uploaded `logo_url` from `edu_exam_types`.

For organizations whose logos are restricted or whose exam category has no single awarding body (for example, university-specific Post-UTME screening or jurisdiction-specific GCSE/CPA pathways), verify usage rights and provider identity before uploading an image.
